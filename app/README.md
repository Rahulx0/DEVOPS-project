# Run and deploy your AI Studio app

This file explains how to run the UrbanGear E-Commerce app locally.

**App Link:** View your app in AI Studio: https://ai.studio/apps/drive/14qxAH9COO0VbgaX7oTwig59WTvcWvCm9

## Run Locally

**Prerequisites:**  Node.js (required to run the app)

**Steps:**
1. Install dependencies:
   `npm install`  <!-- Installs all required packages -->
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key <!-- Required for API access -->
3. Run the app:
   `npm run dev`  <!-- Starts the development server -->
